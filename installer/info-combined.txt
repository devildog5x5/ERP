Coalesce
========

Where ERP and CRM come together.

Next screen asks what THIS computer will be:

  1  BOTH         — Server + Client
     One-PC shops (Recommended)

  2  SERVER ONLY  — data and API
     The host other desks connect to

  3  CLIENT ONLY  — desktop UI
     A workstation talking to an existing Server

Click a card, press 1 / 2 / 3, or double-click to continue.
Next becomes Install Both →, Install Server →, or Install Client →.

Prefer a smaller single-role download?
  CoalesceServerSetup.exe  or  CoalesceClientSetup.exe

After Server is up: sign in with admin / admin
API default: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
