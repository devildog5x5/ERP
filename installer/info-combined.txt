Coalesce
========

Where ERP and CRM come together.

First screen is three big cards — pick exactly one:

  1  BOTH         — Server + Client on this PC  (Recommended)
  2  SERVER ONLY  — data and API host
  3  CLIENT ONLY  — desktop UI for a running Server

Each card has a “Pick if …” line so the right choice is obvious.
The active card shows ✓ SELECTED; the others say “click to pick”.
The bar under the cards restates your choice; Next becomes
Yes — Install Both → / Yes — Install Server → / Yes — Install Client →.

Click a card, press 1 / 2 / 3, use the arrow keys, Enter / Space, or double-click.

Only need one role? Grab CoalesceServerSetup.exe or CoalesceClientSetup.exe
instead (no chooser, smaller download).

Default login after Server is up: admin / admin
API default: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
