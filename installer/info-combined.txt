Coalesce
========

Where ERP and CRM come together.

Next screen asks one obvious question — what should THIS PC run?

  1  BOTH         — Server + Client   (single PC · Recommended)
  2  SERVER ONLY  — data + API host   (Host PC · other desks use Client)
  3  CLIENT ONLY  — desktop UI        (Workstation · needs a Server)

Click a card, press 1 / 2 / 3, or double-click to continue.
The Next button changes to Install Both, Install Server, or Install Client.

Prefer a smaller download for one role only?
  CoalesceServerSetup.exe  or  CoalesceClientSetup.exe

After Server is up: sign in with admin / admin
API default: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
