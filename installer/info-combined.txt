Coalesce
========

Where ERP and CRM come together.

Next you will pick what belongs on THIS PC:

  BOTH    — Server and Client (typical single-PC shop)
  SERVER  — data and API host only
  CLIENT  — desktop UI (needs a running Server)

After Server is up, sign in with admin / admin.
Default API: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
