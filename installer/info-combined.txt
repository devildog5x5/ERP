Coalesce
========

Where ERP and CRM come together.

This installer opens on three obvious cards — pick exactly one:

  1  BOTH         — Server + Client on this PC  (Recommended)
  2  SERVER ONLY  — data and API host
  3  CLIENT ONLY  — desktop UI for a running Server

The Next button becomes Install Both → / Install Server → / Install Client →.
SELECTED marks the active card; the bar under the cards restates your choice
and reminds you that Next installs that role.

Click a card, press 1 / 2 / 3, use the arrow keys, Enter / Space, or double-click.

Already know you only need one role? Prefer CoalesceServerSetup.exe or
CoalesceClientSetup.exe instead (no chooser, smaller download).

Default login after Server is up: admin / admin
API default: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
