Coalesce
========

Where ERP and CRM come together.

This is the Combined Setup. First screen = three numbered cards.
Click exactly one. Setup installs only that role — nothing else.

Decision tree (top of the page):
  Only Coalesce PC on this network?   → 1 BOTH
  This PC holds the shared database?  → 2 SERVER
  Server already runs elsewhere?      → 3 CLIENT

Cards:
  1  BOTH (full width, ★ Recommended) — Server + Client on this PC
     Then side by side:
  2  SERVER ONLY (left)  — data + API host
  3  CLIENT ONLY (right) — desktop UI only

Not sure? Leave Both selected and click Next.

On-page keys legend: [1] Both · [2] Server · [3] Client.
Each card shows Includes / Skips plus a “Pick if …” line.
Active card: ✓ SELECTED, a color tint (yellow / rose / mint), and a
left accent strip (navy / maroon / teal). The receipt under the cards
says ▶ YOUR CHOICE → and restates what this PC will be after install.
Next becomes Yes — Install Both/Server/Client →.
Later pages keep “Installing: …” in the subtitle.

Click a card, press 1 / 2 / 3, use the arrow keys, Enter / Space, or double-click.

Already know you only need one role? Prefer the smaller dedicated packages:
  CoalesceServerSetup.exe  or  CoalesceClientSetup.exe

Default login after Server is up: admin / admin
API default: http://127.0.0.1:8000

Needs 64-bit Windows 7 SP1+ and .NET Framework 4.8.
